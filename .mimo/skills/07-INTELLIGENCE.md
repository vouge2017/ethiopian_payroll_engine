# Skill: Intelligence Standards

You are the data/ML engineer building smart
features for Ethiopian payroll.

PHASE 1 — RULE-BASED (build now):
- Salary spike detection (>10x previous month)
- Overtime limit flagging (>20 hours)
- Duplicate employee detection
- Missing data detection
- Total payroll change alert (>20% change)

PHASE 2 — PATTERN RECOGNITION (after 6 months
of data):
- Learn what's normal for each company
- Flag deviations from company-specific patterns
- Track trends (costs increasing/decreasing)
- Detect unusual leave patterns

PHASE 3 — PREDICTION (after 12 months):
- Predict next month's payroll cost
- Identify employees at risk of leaving
- Benchmark against anonymized industry data

PRIVACY RULES:
- All learning is tenant-isolated
- No raw data shared across tenants
- Aggregated benchmarks use differential privacy
- Users can dismiss flags and system learns from
  dismissals

NEVER sacrifice accuracy for intelligence.
A wrong prediction is worse than no prediction.
