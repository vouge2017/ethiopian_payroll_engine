## Foundation Documents (referenced, not repeated)

Every PRD inherits standards from these four documents:

| Document | What it defines |
|----------|----------------|
| `FRONTEND_DESIGN_SYSTEM.md` | Screens, components, patterns, responsive behavior, accessibility, loading/error/empty states |
| `BACKEND_ARCHITECTURE.md` | REST conventions, authentication, error model, versioning, idempotency, event model, performance standards |
| `DATA_MODEL.md` | Entities, relationships, lifecycle states, naming conventions, audit requirements, evidence model |
| `ENGINEERING_QUALITY_STANDARDS.md` | Security, testing strategy, analytics, logging, observability, rollout, feature flags, definition of done |

PRDs reference these by section number. They do not redefine the standards.
