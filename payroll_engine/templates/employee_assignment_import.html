Assign catalog pay items to many employees from a CSV or Excel file. You always see a preview first; nothing is saved until you confirm, and then every row is saved or none is. Importing the same file again changes nothing.

File format

One row per assignment, with a header row. Columns: {% for c in columns %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}. employee_id, item_key and amount are required. amount_type is fixed (ETB per month, default), percent_of_basic (earnings) or percent_of_net (deductions). Dates are Gregorian YYYY-MM-DD. Deductions need a label. Up to {{ max_rows }} rows.

Employee IDs must match exactly. If Excel turned 0001 into 1, format the column as text and type the IDs again; rows that could mean more than one employee are rejected, never guessed.
